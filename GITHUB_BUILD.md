# Самая простая сборка APK без Android Studio

1. Создайте пустой репозиторий на GitHub.
2. Загрузите в него **содержимое папки VoiceReminder**, а не сам ZIP как один файл.
3. Убедитесь, что файл `.github/workflows/build-apk.yml` тоже попал в репозиторий.
4. Откройте вкладку **Actions** → **Build VoiceReminder APK**.
5. Если сборка не стартовала автоматически, нажмите **Run workflow** → **Run workflow**.
6. После успешной сборки откройте завершённый запуск.
7. Внизу страницы в разделе **Artifacts** скачайте **VoiceReminder-APK**.
8. Внутри скачанного ZIP будет `app-debug.apk` — это установочный файл для Android.
9. Передайте `app-debug.apk` на POCO M6 Pro и откройте его на телефоне.

Если Android предупредит об установке из неизвестного источника, разрешите установку для приложения, через которое открываете APK (например, браузера или файлового менеджера).
